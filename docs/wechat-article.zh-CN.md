# AI 聊天工具越来越复杂，我却只想要一个干净的输入框

## 我需要的东西，正在变少

我叫竹瓜，用过不少 AI 聊天产品。

OpenWebUI、LobeChat，还有各种套着模型 API 的客户端，都折腾过。

它们都很好，功能也越来越全。知识库、插件、角色市场、联网搜索、图片生成、语音、工作流，能塞进去的基本都塞进去了。有些产品打开以后，已经不只是聊天框，更像一套 AI 操作系统。

但用久了，我却发现自己需要的东西正在变少。

不是模型变少，也不是能力变少，而是夹在我和模型中间的东西，越少越好。

我不太需要平台替我安排很多预设角色，也不想每次聊天前先选助手、知识库和工作流。我只想打开一个输入框，把问题扔进去。需要文件就让它读，需要执行就让它调用工具，需要换模型就自己换。

就这么简单。

更准确一点讲，我想要的不是一个功能简陋的聊天网页，而是一个足够纯粹的 AI 入口。

界面可以轻，背景信息可以少，系统提示词别一层套一层，但模型后面的手脚不能被绑住。它仍然要能读项目、看文档、运行命令、调用 Skill、保存会话，也得让我知道它刚才做了什么。

后来我找到了 Pi Agent，突然觉得这些要求并不矛盾。

## Pi Agent 给了我一间毛坯房

很多朋友可能不知道 Pi Agent。

它对自己的定义很克制，一个极简的终端 Agent 框架。

这个定义我很喜欢。

Pi 提供模型、会话、工具和扩展接口，然后把剩下的决定留给使用者。你可以安装 Skills，可以编写 Extensions，可以加入 Prompt Templates，也可以什么都不折腾，就在终端里直接聊。

我自己的感受是，Pi 最打动我的地方不是少了几个按钮，而是它尊重一个很朴素的事实。

每个人真正需要的 AI 工作流，可能都不一样。

有人需要多 Agent 协作，有人需要知识库，有人整天写代码，也有人只是想把一份 Word 或 Excel 交给模型处理。与其让所有人住进同一套精装修样板间，不如给一间门窗水电都齐全的毛坯房，剩下的自己决定。

我寻思了一下，这不就是我一直想要的吗。

但 Pi 原生主要在终端里使用。

终端对我没问题，可我还想在电脑浏览器和 iPhone 上随时打开。人不在桌前，脑子里冒出一个问题，也能拿起手机接着之前的会话聊。

于是我安装了 [agegr/pi-web](https://github.com/agegr/pi-web)。

这是一个做得很好的 Pi WebUI。左边是项目、历史会话和 Explorer，中间是完整聊天，模型、thinking 等级、工具调用、上下文占用和费用都能看见。Pi 仍然在服务端工作，浏览器只是给它多开了一扇门。

这点挺重要。

pi-web 没有再造一套账号、数据库和消息系统。它直接读取这台机器上的 Pi 会话、模型配置、Skill、插件和项目文件。我在终端里的东西，到了网页里还是那些东西。

这种感觉太爽了。

原项目已经很好用，但真正放进日常以后，我还有几个很具体的需求。

## 我先给这扇门加了一把锁

Pi Web 能访问 Pi 用户有权限查看的会话和项目文件，也能让 Agent 调用工具。如果要从局域网访问，甚至经过反向代理放到外面，没有门禁我是不敢用的。

但我也不需要一套企业级账号系统。

这个实例主要就是我自己用，所以我给它加了可选的单密码登录。

设置 `PI_WEB_AUTH_PASSWORD` 后，页面、API、Agent 事件流、文件预览和下载都会一起受到保护。登录状态使用签名的 HTTP-only Cookie，修改密码并重启服务后，旧状态也会失效。

这块必须提醒一下。

它不是多用户权限系统，也不能代替操作系统的文件权限。谁能登录，谁就拥有这个 Pi 用户能够使用的文件和 Agent 能力。远程使用依然需要 HTTPS、强密码和尽可能小的系统权限。

毕竟，这不是一个只会陪你聊天的网页。

它背后连着你的文件、会话和 Agent。

## 四个目录，四种不同的 Pi

第二个需求，是工作目录切换。

一旦让 Agent 真干活，工作目录就是它脚下站着的那块地。

在我的使用方式里，`home`、`code`、`work`、`super` 不只是四个文件夹，而是四套不同的使用环境。

`home` 最干净，不加载额外的 Skill 和插件，只保留 Pi Agent 的核心功能。这里的系统提示词和背景信息最少，适合纯粹聊天，也适合处理那些不需要复杂工具的问题。

`code` 加入编程相关的扩展和 Skill，专门用来读代码、改项目、跑命令。

`work` 放办公文件处理和日常娱乐相关的 Skill。Word、Excel、PDF 之类的材料，大多从这里处理。

`super` 则是完全体，加载我所有的 Skill 和扩展。碰到复杂任务，或者我自己也不确定最后会调用什么能力时，就直接进这里。

以前切换这些环境，要在最近会话和路径里反复找。一次只浪费几秒，但每天来回切十几次，还是很打断思路。

于是我把它们做成了固定快捷入口。

点一下，当前工作目录、会话列表和文件 Explorer 就一起切过去。原项目本来就支持最近项目和 Git worktree，我没有再造一套项目管理，只给最高频的几个位置留了直达入口。

这可能是整个改造里最私人化的功能。

但有些功能不需要适合所有人。只要它能让自己每天少点几下鼠标，少打断几次思路，就值得。

## 把 Pi Agent 装进 iPhone

回到手机这块，我做的第三件事，是把它补成了 PWA。

现在可以通过 Safari 把它添加到 iPhone 主屏幕，也处理了刘海和底部安全区域。打开以后更像一个独立应用，不用再去一堆浏览器标签里找。

不过，这个 PWA 不支持离线聊天，而且我是故意这么做的。

Pi 的会话、项目文件和 API 响应可能包含敏感信息，也可能随时变化。如果 Service Worker 为了秒开把它们缓存到手机里，不但可能显示过期状态，还会让工作区数据多留一份副本。

所以它只解决安装形态和手机体验，不缓存会话、文件与 API 数据。

有些能力不做，也是设计的一部分。

## 把 Word 和 Excel 直接扔进聊天框

然后是我自己最常用的一块。

文件拖拽。

原来的 Explorer 已经能上传文件，图片也可以拖进聊天区作为视觉附件。但我平时接触更多的是 Word、Excel、PDF、ZIP 和各种工作文件。

我想要的动作很简单。

把文件直接扔进聊天框，就像把一份材料推到同事桌面上，然后说一句，帮我看看这个。

现在把文件拖进聊天区域，页面会先判断类型。图片继续作为视觉附件，Word、Excel、PDF、ZIP 和其他普通文件会上传到当前工作目录。图片和文档一起拖进来，也会自动分开处理。

上传成功后，Explorer 会自动刷新，输入框里还会插入 `@文件名`。

不用找路径，也不用再手打一遍文件名。

这一下，网页和本地工作目录就接上了。

拖拽背后还有一些不显眼但很重要的细节。同名文件可以选择替换、跳过或取消，上传过程有冲突预检查、进度和结果提示。如果上传中途切换了工作目录，旧请求也不会跑到新会话里插入文件引用。

看起来只是把文件拖进去，认真做完却要处理一堆边角。

但工具是否顺手，往往就藏在这些没人会截图展示的地方。做对了，你感觉不到它。做错了，一个文件名或一条路径就能把注意力拽走。

## 少的，是中间层

说到这里，我想起 Dieter Rams 那句很有名的话，少，却更好。

这句话经常被理解成少放几个按钮，多留一点白。但这次自己改 Pi Web，我突然觉得，真正的少不是页面上的东西少，而是一个动作和目的之间的阻力足够少。

我要聊，就直接打开聊。

我要换目录，就点一下。

我要给它一份 Excel，就把 Excel 扔进去。

我要在手机上继续，就从主屏幕打开。

我要让它替我工作，也能看见模型、thinking、工具调用和上下文，而不是被一层漂亮的聊天气泡挡住。

少的，是中间层。

保留下来的，是控制权。

我没有把 OpenWebUI 和 LobeChat 当成反面例子。它们服务更广的人群，也解决了不同的问题。如果你需要多用户、知识库和完整的平台体验，它们可能更合适。

但如果屏幕前的你也用过一圈产品，发现自己每天做的仍然只是打开对话、丢进文件、让模型开始干活，那你可能也会喜欢 Pi 这条路。

它没有试图成为所有人的 AI 首页。

它更像一套可以被你拧成自己形状的工具。

这个增强版基于 agegr/pi-web `v0.7.16` 修改。我只是在原项目扎实的基础上，补了自己最需要的认证、PWA、工作目录快捷入口和聊天文件上传。

项目地址

[zhuguadundan/pi-web-secure](https://github.com/zhuguadundan/pi-web-secure)

它还不是一个能在 App Store 里点一下就用的成熟应用。你需要一台运行 Pi 的服务器或 NAS，安装 Node.js 和 Pi，再 clone 项目进行构建。如果要在公网使用，还要自己处理 HTTPS 和反向代理。

直接运行 `npx @agegr/pi-web` 安装的是上游原版，不包含这个 fork 新增的功能。增强版的完整安装步骤，已经写在仓库的中文 README 里。

还有一句必须提醒。

不要把实例直接裸露在互联网。

至少要有 HTTPS 和强密码，最好放在可信私网或受控的反向代理后面。

因为你打开的不是一个普通网页，而是通向自己文件、会话和 Agent 能力的一扇门。

写到这里再回头看，我好像并没有给 Pi Agent 做一个更强大的 AI 平台。

我只是把那扇门修得更适合自己。

加一把锁，让它能从手机打开，门边放几个常用目录，再让 Word 和 Excel 可以直接递进去。

就这些。

但正是这些很小、很私人的改动，让它从一个我觉得不错的开源项目，变成了一个我每天愿意打开的东西。

我有时候觉得，AI 时代真正有意思的能力，不只是学会使用一个又一个新产品。

而是慢慢知道自己到底需要什么，然后把工具改成那个样子。

不是适应工具。

是让工具适应你。

玩得开心，下次再见。
